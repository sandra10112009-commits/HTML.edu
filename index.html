🌐 ¿Qué es HTML?

HyperText Markup Language

HTML es un lenguaje de marcado utilizado para crear y organizar el contenido de las páginas web. Permite estructurar textos, títulos, imágenes, enlaces, listas, formularios y otros elementos.


HTML funciona mediante etiquetas que indican al navegador qué tipo de contenido debe mostrar.

📄 index.html
<h1> Mi página web </h1>
<p> Bienvenidos </p>
<a href= "#" > Enlace </a>

🏗️ Estructura básica de HTML

<!DOCTYPE html>
<html>
  <head>
    <title>Mi página</title>
  </head>
  <body>
    <h1>Hola mundo</h1>
    <p>Mi primera página</p>
  </body>
</html>

🎨 ¿Qué es CSS?

🎨

Diseño

CSS permite cambiar colores, tamaños, fuentes y otros aspectos visuales de una página.

📐

Distribución

Permite organizar los elementos de una página y crear diferentes diseños.

✨

Animaciones

CSS también puede crear transiciones y diferentes efectos visuales.

⚙️ ¿Qué es JavaScript?

💡 Interactividad

JavaScript es un lenguaje de programación que permite agregar comportamiento e interacción a las páginas web.

🖱️ Acciones

Puede utilizarse para responder a acciones del usuario, como hacer clic en botones, completar formularios o interactuar con diferentes elementos.
